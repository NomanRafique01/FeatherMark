
# FeatherMark v2.0.2

This release adds multi-folder workspace tabs so you can keep several project
folders open and switch between them without losing your place.

## Workspace improvements

- **Multiple open folders** — open more than one folder and switch between folder
  tabs from the workspace header.
- **Closeable folder tabs** — each folder tab has an inline × control that removes
  the folder from the current workspace without deleting any files from disk.
- **Open another folder** — use the + control beside the folder tabs to add another
  folder quickly.
- **Folder switching** — selecting a folder tab updates the workspace explorer to
  that folder's tree while leaving document tabs intact.
- **Workspace persistence** — open folder tabs and the active folder are restored
  when FeatherMark starts again.
- **Backward compatibility** — existing single-folder workspace settings continue
  to restore normally and are upgraded to the multi-folder format as folders are
  opened or closed.

## Included in the release

- Windows x64 installer: `FeatherMark-Setup-2.0.2.exe`
- Existing FeatherMark editor, Markdown rendering, themes, document tabs,
  recents, session restore, and Windows file associations

## Compatibility

- Windows 10 or Windows 11, 64-bit
- No runtime internet connection required
